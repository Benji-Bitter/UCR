what it is

A real radio protocol stack, not a website mockup. Devices running UCR exchange Ed25519-signed packets over whatever wire exists — LoRa silicon (ESP32-S3 + SX1262), LAN broadcast, TCP gateways, or serial — and route them through an intelligent multi-hop mesh. Every message is signed at the origin and verified at every hop. DMs are end-to-end encrypted (X25519 + ChaCha20-Poly1305); relays forward ciphertext they can't read.

Channels for public talk · encrypted DMs · private groups · emergency broadcasts that bypass your PIN lock · digital morse · push-to-talk voice where the link budget allows · a deterministic RF simulator for development.

what already works

  • Self-certifying identity — Ed25519 keys, NodeId = blake3(pubkey)[..16]. No CA, no registration.
  • Multi-hop mesh routing — scoped flooding, passive route learning, RREQ/RREP, dedup, store-and-forward, acks + retry.
  • Real transports — UDP LAN broadcast, TCP gateways, USB serial modem, mux across all of them. Zero WebSockets, zero internet.
  • LoRa-honest — 222-byte wire MTU (SX1262 FIFO is 255), measured signed overhead, airtime-paced beacons (~37s at SF9), text chunking, duty-cycle aware.
  • Hardware autodetect — plug in a modem, UCRPING handshake identifies it, the node retunes itself to the link.
  • Packet voice — signed IMA-ADPCM PTT frames on capable links; Codec2 is the registered LoRa voice path (id 2).
  • Digital lock — PIN-gated transmit like a real handheld: rx/relay continue, SOS bypasses, blake3 PIN hash, boots locked.
  • GPS kill-switch — coarse (city-level) position announce, toggleable; the fix stays local when off.
  • Emergency — signed, priority-flooded, relayed regardless of blocking; local rate-limit.
  • Deterministic RF simulator — seeded medium with path loss, collisions, half-duplex, partitions. Test the mesh without hardware.

run it

# clone + prove the stack
git clone https://github.com/Benji-Bitter/UCR && cd UCR
cargo test --workspace

# two terminals, real mesh — zero config
cargo run -p ucr-cli --bin ucr-node -- --callsign ALPHA
cargo run -p ucr-cli --bin ucr-node -- --callsign BRAVO

# the app
cd apps/desktop && pnpm install && pnpm tauri dev

two nodes on one LAN find each other over UDP broadcast alone — no config, no account, no server.
